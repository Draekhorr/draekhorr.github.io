# Draekhorr — WoW Legacy (V1)

An unofficial, responsive World of Warcraft character showcase for Draekhorr (EU Draenor), focused on raiding, Mythic+, and Restoration Shaman history.

## Features

- Character profile with Blizzard portrait, item level, achievement points, and lifetime death statistics.
- Current raid progression and expansion-grouped historical raids. Cutting Edge badges are based on verified achievements, never inferred from Mythic clears.
- Warcraft Logs boss icons, best healing parses, and highest HPS where available.
- Raider.IO current/previous Mythic+ scores, dungeon runs, times, and icons.
- Dynamic guild name and link in the header, when guild data is available.
- Responsive layouts for mobile, tablet, desktop, and ultrawide monitors.

## Data and automation

`data.json` is generated by `scripts/sync_all.py` using Blizzard, Raider.IO, and Warcraft Logs. The scheduled GitHub Actions workflow runs at 00:00, 06:00, 12:00, and 18:00 UTC (`0 */6 * * *`), subject to GitHub scheduling delays. Guild synchronization and health monitoring use additional scripts/workflows where configured. Monthly critical-failure reporting uses GitHub Issues and GitHub notifications when enabled.

The frontend reads `data.json`; it does not contain API credentials. API secrets belong in GitHub Actions Secrets.

## Project files

- `index.html` — page structure and content.
- `style.css` — shared typography, colors, spacing, responsive rules.
- `script.js` — dynamic rendering of API data.
- `data.json` — generated character and progression data.
- `scripts/` — data collection and monitoring scripts.
- `.github/workflows/` — scheduled sync and reporting.

## Visual design

The CSS is organized by component, with shared tokens under `:root`. Maintain the existing component classes and DOM IDs because `script.js` relies on them. Prefer editing an existing rule over appending a version-specific override. Review at 320, 375, 430, 768, 1024, 1440, and 3440 CSS-pixel viewport widths.

## Known limitations

- Future raid discovery depends on the completeness of Blizzard and Raider.IO metadata; unknown raids should not be classified speculatively.
- Warcraft Logs and CDN media may omit some values or icons.
- The previous raid-boss-kills audit was inconclusive; that counter is not displayed.
- GitHub email notifications for monthly Issues depend on account settings.

## Versioning

**V1** is the current documentation baseline. This UI cleanup consolidates legacy CSS overrides without changing the API sync logic. Update this same README with future functional changes.
